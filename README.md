# WUYI Cake 當週公版蛋糕訂購

線上公版蛋糕訂購系統，提供三步驟流暢訂購體驗，填寫完成後自動產生純文字明細並跳轉至 LINE 官方帳號進行客服報價確認。

## ✨ 特色功能

1. **三步驟訂購流程**：
   - 步驟 1：公版照片卡片直接勾選與點擊放大檢視。
   - 步驟 2：完全隨機口味安排（附忌口與過敏備註欄）、緞帶顏色更換。
   - 步驟 3：加購品項、取貨日期與自取時段、訂購人聯絡資料、注意事項打勾確認。

2. **店長日期管理後台（方案三：GitHub API 自動化）**：
   - **進入方式**：連續點擊頂部橫幅蛋糕圖片（或公版蛋糕照片、標題 🎂）**3 下**。
   - **店長密碼**：`5151`（支援半形 `5151` 或全形 `５１５１`）。
   - **每一天皆可單獨開關**：
     - 清單列出未來每一天（如 2026-10-28 週三）。
     - 點擊該天即可切換「🟢 可訂購」或「🔴 已公休/額滿」。
     - 支援「全部開放」、「全部關閉」、「依通則重設」。
   - **同一個乾淨網址永遠不變**：
     - 客人開啟永遠是：`https://a0952015080-netizen.github.io/wuyi-order/`
     - 網頁自動載入 `schedule.json`，店長改完日期後，在管理後台點擊「**儲存並自動推送到 GitHub**」，網頁背景直接呼叫 GitHub API 更新 `schedule.json`，店長**完全不用開 GitHub 貼 HTML 代碼**！

3. **如何設定 GitHub API Token（只需設定一次）**：
   1. 登入 GitHub，點擊右上角頭像 ➔「Settings」。
   2. 頁面左側滑到底部 ➔ 點「Developer settings」。
   3. 點選「Personal access tokens」➔「Tokens (classic)」➔「Generate new token (classic)」。
   4. Note 填寫 `wuyi-cake`，Expiration 選 `No expiration`（無期限），勾選 `repo`（完整儲存庫寫入權限）。
   5. 點擊綠色「Generate token」，將產生的 `ghp_...` 貼在店長後台的 GitHub Token 欄位。
   6. Token 僅會保存在店長手機瀏覽器本機，客人看不到也無法取得。

4. **LINE 訂單純文字格式（無 Emoji）**：
   - 跳轉至 LINE 或點擊複製訂單明細時，自動過濾並移除所有 Emoji 表情符號，呈現乾淨俐落的純文字排版，方便客服複製與建檔。
