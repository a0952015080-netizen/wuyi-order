# WUYI Cake 當週公版蛋糕訂購

線上公版蛋糕訂購系統，提供三步驟流暢訂購體驗，填寫完成後自動產生純文字明細並跳轉至 LINE 官方帳號進行客服報價確認。

## ✨ 特色功能

1. **三步驟訂購流程**：
   - 步驟 1：公版照片卡片直接勾選與點擊放大檢視。
   - 步驟 2：完全隨機口味安排（附忌口與過敏備註欄）、緞帶顏色更換。
   - 步驟 3：加購品項、取貨日期與自取時段、訂購人聯絡資料、注意事項打勾確認。

2. **店長日期管理後台（隱藏功能，免進 GitHub 修改）**：
   - **進入方式**：連續點擊頂部橫幅蛋糕圖片（或公版蛋糕照片、標題 🎂）**3 下**。
   - **店長密碼**：`5151`（支援半形 `5151` 或全形 `５１５１`）。
   - **每一天皆可單獨開關**：
     - 清單列出未來每一天（如 2026-10-28 週三）。
     - 點擊該天即可切換「🟢 可訂購」或「🔴 已公休/額滿」。
     - 支援「全部開放」、「全部關閉」、「依通則重設」。
     - 可自由設定最少提前天數（當日、明日、2天後、3天後）與開放天數範圍。
   - **免進 GitHub 貼 HTML 機制**：
     - **儲存於此裝置**：點擊儲存立即於本機生效。
     - **複製最新預訂連結**：點擊「🔗 複製最新預訂連結」，直接產生帶有最新日期開關參數的網址。店長只要將該連結設定在 LINE 官方帳號圖文選單、歡迎訊息或 IG 自介，客人點開即時同步最新可訂購日期，完全不需開啟 GitHub 貼程式碼！

3. **LINE 訂單純文字格式（無 Emoji）**：
   - 跳轉至 LINE 或點擊複製訂單明細時，自動過濾並移除所有 Emoji 表情符號，呈現最乾淨、俐落的純文字排版，方便客服複製與建檔。
