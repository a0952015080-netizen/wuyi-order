# WUYI 蛋糕訂購預訂單

線上蛋糕預訂系統，填寫後自動整理訂購明細並跳轉 LINE 官方帳號進行客服報價確認。

## ✨ 特色功能

1. **一頁式訂購流程**：尺寸與口味自動聯動、加購項目互斥防呆、取貨時間選擇、訂購人聯絡資訊。
2. **店長後台管理（隱藏功能）**：
   - 點擊表頭標題的蛋糕圖案 **🎂**
   - 輸入管理密碼：`5151`（支援全形 `５１５１` 或半形 `5151`）
   - 可即時修改：
     - 最少提前預約天數（預設 3 天）
     - 每日超過 18:00 自動延後 1 天（起算機制）
     - 固定每週一公休開關
     - 自訂額外休假 / 滿單不可預訂日（支援新增與刪除）
     - 特例開放預訂日（即使是週一也能單獨開放接單）
   - 設定即時生效並保存在瀏覽器。
3. **LINE OA 跳轉**：一鍵產生標準格式訂單訊息，並附帶貼心防漏單提醒。
